# 系统架构

```text
5× WT901BLECL IMU
       │ BLE
       ▼
ESP32-S3 主控
       │
       ├─ 传感器连接管理 / 时间戳 / 缓冲
       ├─ 姿态与人体语义坐标
       ├─ 动作状态机 / ROM / 质量评价
       ├─ MotionFrame 统一语义数据
       ├─ SD 本地记录
       ├─ NVS 断电续训检查点
       ├─ UART → 7寸屏
       ├─ UART → 离线语音模块
       └─ Wi-Fi → 云端同步（接口联调层）
                       │
          ┌────────────┴────────────┐
          ▼                         ▼
      患者/家属小程序             康复师管理端
          │                         │
          └────── 处方/报告闭环 ────┘
```

## MotionFrame 语义层

统一封装：动作ID、动作阶段、关节角度、目标角度、动作平面偏差、代偿指标、稳定性、质量结果、次数、组数、时间戳和设备状态。游戏、屏幕、SD、云端均消费同一语义数据，避免直接依赖底层 IMU 原始坐标。
