# Integration & Validation Checklist

本文件用于后续工程迭代记录，不参与运行时逻辑。

## 动作参数调优

- 每个动作采集标准动作与典型错误动作日志
- 复核起始姿势、目标角度、返回阈值
- 复核不同佩戴松紧和重复佩戴后的稳定性
- 检查整体转身与局部平面偏移的区分
- 检查错误提示与屏幕反馈时序

## 系统联调

- 主控与屏幕 UART 命令双向测试
- 5 IMU 掉线与自动重连
- SD 写入与断网连续训练
- 断电检查点恢复
- 处方同步消息解析
- 网络恢复后的同步队列
- 游戏触发只接受合格动作
- 数字孪生帧率和错误高亮

## 发布前

- Arduino 主控完整编译
- PlatformIO 7 寸屏完整编译
- 样例数据与真实训练日志分目录保存
- 更新参数版本号和变更日志
