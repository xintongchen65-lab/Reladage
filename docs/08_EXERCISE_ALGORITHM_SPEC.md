# RehabMotion 8 动作算法规格

本文件描述统一动作引擎中的八个动作模块。每个模块均采用 `MotionFrame -> phase detector -> RepMetrics -> quality flags -> telemetry/game event` 的处理链。

## 1. 哑铃弯举 / 屈肘训练
- 传感器：A 上臂、B 前臂、E 腰腹参考。
- 校准：起始静止 -> 缓慢标准屈肘 -> 返回静止；学习屈伸轴方向与动作符号。
- 阶段：READY -> ACTIVE -> PEAK -> RETURNING -> REP COMPLETE。
- 主指标：肘关节屈曲 ROM。
- 评价：ROM、上臂代偿、运动平面、躯干倾斜、速度、稳定性。
- 游戏：划船挑战；只有完成且动作质量通过的动作触发 `pull`。

## 2. 肱三头肌伸展
- 传感器：A/B/E。
- 校准：固定上臂完成一次慢速伸肘与返回。
- 主指标：肘关节伸展 ROM。
- 评价：上臂漂移、平面偏差、躯干后仰、动作速度、稳定性。
- 游戏：摘水果；有效伸肘触发 `reach`。

## 3. 肩胛平面抬手
- 传感器：A/B/E。
- 校准：学习标准肩胛平面抬举轨迹。
- 主指标：肩部抬举角。
- 评价：平面偏差、上臂异常轨迹、躯干倾斜、速度、稳定性。
- 游戏：摘水果；达到目标抬举高度且质量合格触发 `catch`。

## 4. 墙面爬手
- 传感器：A/B/E。
- 校准：面向墙完成一次慢速上爬/返回。
- 主指标：抬举角与垂直位移的组合信号。
- 评价：高度不足、平面偏差、身体前倾、速度、稳定性。
- 游戏：打地鼠；达到目标高度后触发 `hit`。

## 5. 膝关节屈伸
- 传感器：C 大腿、D 小腿、E 腰腹参考。
- 校准：保持大腿稳定完成一次慢速膝屈伸。
- 主指标：膝关节屈伸 ROM。
- 评价：ROM、膝轨迹平面、躯干稳定、左右差异、速度、稳定性。
- 游戏：点球大战；有效动作触发 `kick`。

## 6. 坐到站训练
- 传感器：C/D/E，A/B 可作为上肢扶持与代偿辅助通道。
- 校准：坐稳 -> 起立 -> 站稳 -> 坐回。
- 主指标：膝髋相位与垂直位移组合信号。
- 评价：未完全站起、前倾过大、左右偏载、稳定性。
- 游戏：活力公园；完整循环触发 `advance`。

## 7. 箱式深蹲
- 传感器：C/D/E，A/B 为辅助姿态通道。
- 校准：站稳 -> 后坐下蹲 -> 接近箱面 -> 站起。
- 主指标：下蹲深度/膝角。
- 评价：深度、前倾、左右不对称、膝轨迹平面、稳定性。
- 游戏：平衡步道；合格动作触发 `step`。

## 8. 台阶踩踏 Step Up
- 传感器：C/D/E，A/B 可监测扶持代偿。
- 校准：站稳 -> 踩上低台阶 -> 稳定支撑 -> 回到地面。
- 主指标：垂直位移和膝关节角组合信号。
- 评价：抬腿高度、躯干、左右差异、稳定性、步频。
- 游戏：台阶冒险；合格动作触发 `climb`。

## 通用单次动作统计字段

`RepMetrics` 在一次动作期间持续累计：
- `peakRomDeg`
- `durationMs`
- `maxAbsSpeedDegS` / `meanAbsSpeedDegS`
- `minStability` / `meanStability`
- `maxUpperArmDeviationDeg`
- `maxPlaneDeviationDeg`
- `maxTorsoTiltDeg`
- `maxAsymmetryDeg`
- `maxForwardLeanDeg`
- `maxVerticalExcursionDeg`
- `peakCadenceRpm`

单次动作结束后同时输出主错误码和 `qualityFlags` 位图，便于屏幕、报告、游戏和云端同时消费同一份动作质量结果。
