RehabMotion v5 视频拍摄展示增强版

基线：
- 主控：RehabMotion_v5 + 断电续训 + IMU启动状态清零
- 7寸屏：V4.4.28 首次IMU页跳首页修复版

本次只改“展示证据”，不修改动作识别算法、ROM、平面判定、U/P/T阈值、K11。

1. 正确动作大提示
- 每次完整动作最终判定为 GOOD 后，7寸屏中央显示绿色“动作正确”约1.6秒。
- 用于拍摄“整体转身但动作仍正确”时，让评委明确看到系统确实给出正确判定。

2. 错误提示更适合视频
- 幅度不足 / 上臂代偿 / 动作平面偏移 / 躯干代偿仍沿用原来的大字提示。
- 大弹窗保持时间统一提高到约1.6秒，方便镜头捕捉。

3. 断电续训恢复提示
- 断电重启后仍要求重新完成新鲜的BODY-FRONT + K11校准。
- 保存进度恢复并进入正式训练时，中央绿色显示“训练已恢复”约2.3秒。
- 训练次数/组数仍由原断电续训逻辑恢复，本提示仅用于UI证明。

4. E腰腹参考节点强调
- IMU佩戴页E行显示“腰腹 + 参考”，并用浅绿色边框/背景强调。
- E仍是原算法中的腰腹参考节点，本次只是把角色在屏幕上说清楚。

5. IMU初始状态
- 7寸屏本地初始连接状态改为全未连接；收到主控实时mask后逐项刷新。
- 与主控开机主动发送0x00清缓存逻辑配合，避免上一轮全绿残留。

视频前快速验证：
A. 正确动作x1 -> 中央应出现绿色“动作正确”。
B. 幅度不足/平面偏移任一x1 -> 中央出现对应红色错误提示。
C. 整个人转90度，手相对身体做正确动作 -> 仍出现绿色“动作正确”。
D. 做2次后直接断电 -> 重启 -> 重新校准 -> 倒计时结束进入训练 -> 出现“训练已恢复”，次数保持2/10。
E. IMU佩戴页E行可直接看见“腰腹 参考”。

注意：
- 主控和7寸屏两个工程都需要更新，否则0x20/0x40两个新UI提示不会完整显示。
- 这里未使用用户电脑上的Arduino/PlatformIO工具链做实机编译，不宣称已在目标硬件上编译烧录通过。
