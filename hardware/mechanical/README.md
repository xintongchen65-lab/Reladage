# Mechanical / CAD files

Team-designed mechanical files used by Reladage are stored here.

## Included design

- [`wt9011dcl_wearable_mount/`](./wt9011dcl_wearable_mount/) — WT9011DCL-BT50 wearable enclosure and strap-holder iterations, including printable STL files, editable OpenSCAD source for V1/V3, design notes and V3 preview images.

## Repository policy

Recommended source/export formats include `.scad`, `.step` / `.stp`, `.3mf` and `.stl`. Slicer caches, printer temporary files and generated G-code are not committed unless specifically required for judging.

The included CAD files are small enough for ordinary GitHub storage; Git LFS is only needed if a future individual binary file exceeds the normal GitHub file-size limit.
