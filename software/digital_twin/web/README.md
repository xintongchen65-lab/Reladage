# Reladage Digital Twin Demo

Independent Vite page for the iCAN video recording.

```powershell
cd reladage-digital-twin-web
pnpm install
pnpm dev
```

Open `http://127.0.0.1:4174/` (or the URL printed by Vite). The page uses a right-aligned panel that is 60vw wide and fills the available height. Use the bottom controls to replay, pause, jump between the four demo states, or enter fullscreen.
