# RehabMotion 游戏中心与「点球大战」V1

主包游戏中心只显示可扩展游戏卡片。每个游戏普通分包独立拥有首页、单人/多人入口、训练记录、正式训练页面与运行素材；`game-platform`提供不依赖Vue和全局状态的公共协议、EventChannel导航、记录存储和多人基础设施。

点球大战对应膝关节屈伸。标准帧是`KneeMotionFrame`，正式输入固定为`lower / knee_flexion`，`active_side`可选但适配后必有值。Fake默认25Hz、3组、每组左右各10次、目标80°、有效60°、返回20°，角度路径为低角度伸膝→屈膝增角→伸膝返回。RealDataSource只消费主控判定结果。

每次有效动作只生成一次射门。方向左/中/右等概率，结果概率为进球70%、被扑20%、射偏10%。康复次数和完成状态完全服从Motion JSON；射门、进球、扑救、射偏、得分和连击由点球规则维护。REST、暂停、后台、断流冻结动画任务、射门、计分及有效训练时长。

多人房间在公共协议中携带`gameId`，不同游戏不能互相加入。点球PK使用房间种子按射门序号产生可复现的基础方向和结果；合作目标为`ceil(人数×组数×每组次数×2×70%)`个进球。达到目标只标记团队挑战成功，不会提前结束任何成员的康复训练。

点球母版保存在`design/penalty`，运行素材由`scripts/process-penalty-assets.py`裁切、去背和压缩。中文、数字与HUD均为页面真实文本。点球分包与摘水果分包分别保持低于1.8MiB。
