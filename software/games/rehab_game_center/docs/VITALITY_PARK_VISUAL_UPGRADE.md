# RehabMotion《活力公园》V1 视觉升级说明

## 已锁定的视觉原则

- 人物以统一六姿态母版为唯一标准：坐稳、前倾准备、离椅、半站立、完全站立、下坐回位。
- 六张人物图均为独立透明 PNG，不含椅子；统一 260×430 透明画布、脚底锚点与人物比例。
- 公园长椅为独立固定层，训练全程不随人物姿态切换而消失。
- 场景拆为远景、中景、前景三个绘制层；人物和长椅位于前景交互层。
- 小鸟、花坛、路灯、蝴蝶、喷泉、风筝、小狗、彩旗、彩虹、庆祝效果均作为场景元素逐步出现，不使用大尺寸圆形图标悬浮。
- HUD 只保留总体进度、本组次数、组数、暂停；动作提示独立放在底部区域。
- REST 时不重置公园，不隐藏长椅；仅增加半透明休息遮罩。

## 动作映射

真实数据按以下优先级驱动人物：

1. `motion_progress`
2. `motion_stage`
3. 主控关节角度映射

人物姿态在起立方向按：

`坐稳 → 前倾 → 离椅 → 半站立 → 完全站立`

下坐方向按：

`完全站立 → 半站立 → 离椅 → 前倾 → 下坐回位 → 坐稳`

`rep_event` 只用于确认一次有效动作完成，并负责场景激活/计数，不用于游戏侧医学动作判断。

## 场景激活顺序

1. 小鸟
2. 花坛开放
3. 路灯亮起
4. 蝴蝶
5. 喷泉启动
6. 风筝
7. 小狗
8. 彩旗
9. 彩虹
10. 庆祝状态

## 响应式目标

游戏页采用横屏视口百分比布局，不依赖固定手机像素。重点适配：

- 667×375
- 844×390
- 932×430

人物、长椅、HUD、底部动作提示均使用独立定位和层级，避免相互遮挡或姿态切换时漂移。

## 素材目录

- `static/character/`：六姿态透明人物
- `static/props/bench.png`：独立长椅
- `static/backgrounds/park-far.webp`：远景底图
- `static/backgrounds/park-mid.png`：中景透明层
- `static/backgrounds/park-foreground.png`：前景透明层
- `static/events/`：10 个场景激活事件
- `static/effects/ground-shadow.png`：人物/椅子接地阴影

素材生产源统一使用高分辨率透明母图，运行素材再缩放导出，避免白边、黑边和相邻素材串入。
