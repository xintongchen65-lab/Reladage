# 地鼠大作战 V1.5 视觉修正说明

本次修正不改变箱式深蹲动作判定、多组训练、2–5 人房间制 PK/合作等既有架构，重点将游戏画面替换为此前已确定的卡通素材体系。

- 5 个洞口固定存在，每个洞口拥有独立地鼠角色；单人模式其余洞口为 NPC，多人模式按加入顺序映射到 5 个固定洞位。
- 地鼠素材改为此前设计稿中的 5 套不同皮肤：安全帽、红头巾、绿叶、护目镜和基础款。
- 锤子改为此前设计稿中的红色星星玩具锤，并在五个洞口之间移动。
- `WARNING` 时在目标洞口显示设计稿中的黄色警示光圈；当目标为本机玩家时明确提示“锤子来了，请下蹲躲避”。
- 本机 `motion_progress` 继续实时控制地鼠下沉；达到躲避位置仅改变视觉状态，最终仍由主控 `both_rep_done` / count 增量确认一次完整有效箱式深蹲并结算。
- 删除旧版本中占据大部分场地的扁平椭圆“沙坑”，改用明亮草地、远山与天空背景，让洞口本身成为场景物件。
- 命中、警示、金币、胡萝卜、星星等均换为同一套设计稿素材。
- 暂停与退出保持并存；暂停遮罩中仍可继续或退出训练。

运行素材经过重新缩放与压缩，地鼠游戏分包素材约 1.08 MiB，低于 1.8 MiB 目标。
